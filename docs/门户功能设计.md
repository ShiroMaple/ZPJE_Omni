要将 Omni 从一个 MVP 工作台升级为长久立足的企业级门户平台，核心思想是**将“代码硬编码”解耦为“配置与数据驱动”**。

结合现有的 Next.js 全栈技术栈与致远 OA 单点登录体系，建议从以下三个维度规划功能模块：

## 一、 扩展性（Extensibility）：支持业务无限生长

门户站不能每次上线新系统都去改代码、重新打包发布。

- **动态应用注册中心（App Registry）**
  - **元数据管理**：后台支持动态增删改查子应用（应用名称、图标、简介、访问 URL、所属分类、环境标签等）。
  - **应用分类与标签系统**：按部门/业务域分类（如：`生产制造`、`质量管理`、`能源看板`），支持自定义标签过滤。
- **RBAC 角色权限与可见性隔离**
  - **菜单/应用粒度控权**：结合致远 OA 传递的用户角色或部门（如 `loginName` 映射的角色），控制某些敏感应用卡片（如 `CarbonPlatform`）仅特定权限组可见。
- **微组件/插件化工作台（Widget System）**
  - **卡片式数据暴露**：子应用（如 `supos_Kanban` 或 `WeldSnap`）不仅提供网页链接，还可以提供轻量级 API 接口。门户站直接在首页渲染微卡片（如“当前异常焊口数：2”、“今日能耗总量”），无需跳转即可查看核心指标。

## 二、 易用性（Usability）：提升全员办公效率

门户是员工每天上班打开的第一个页面，体验必须做到“极简、高效”。

- **个性化工作台（Personalized Workspace）**
  - **常用应用收藏（Favorite Apps）**：允许用户置顶或收藏自己高频使用的 3~5 个子系统。
  - **最近使用历史（Recently Used）**：自动记录并呈现用户近期访问过的应用，减少查找路径。
- **全局搜索 / 全局指令面板（Command Palette / `Ctrl + K`）**
  - 支持键盘快捷键弹出全局搜索框，输入拼音/关键字即可快速模糊匹配并打开子应用或直达特定功能页。
- **统一待办与消息聚合（Unified Notification Hub）**
  - 轮询或通过 Webhook 接收致远 OA 的待办公文数量以及各子系统的关键告警（如 `DocEx` 解析完成通知），在门户 Header 统一提醒。
- **单点登出（SLO）与身份管理**
  - 明确的用户 Profile 区域，提供一键“退出登录”功能（自动清空本地 Cookie 并通知致远 OA 释放会话）。  

## 三、 维护性（Maintainability）：降低运维成本与故障率

运维人员需要能时刻把控整个门户生态的健康状况。

- **应用健康探活与故障降级（App Health Monitor）**
  - **自动心跳检测**：门户后台定时（如每 30 秒）向各个子系统（`weldsnap.izpje.com`、`fabflow.izpje.com` 等）发起 HTTP 探活请求。
  - **状态可视化**：自动在卡片上标明 `运行中`、`响应迟缓` 或 `服务维护中`。若服务挂掉，点击卡片时友情提示，而不是直接弹 Nginx 502 报错。
- **应用维护模式与公告发布（Maintenance Banner）**
  - **单应用维护锁定**：某个子系统（如 `DocEx`）要升级部署时，管理员可在门户后台将该应用设为“维护中”，禁止普通用户点击跳转。
  - **全网公告栏**：发布系统停机维护通知或公司重大 IT 变更公告。
- **访问审计与行为日志（Audit Logging）**
  - 记录“谁在什么时间通过门户访问了哪个子系统”（包含 IP、时间、用户账号）。
  - 自动统计各个子应用的**访问频次热度榜**，为后续系统迭代和服务器资源分配提供数据支撑。

## 四、 推荐的架构功能演进路线

Plaintext

```
【第一阶段：基础运维与扩展】（建议优先落地）
  ├── 1. 动态应用数据库（代替硬编码 app 列表）
  ├── 2. 子应用健康探活（自动判断 200/500/502 状态）
  └── 3. 完整单点登出（SLO 通知致远 OA）

【第二阶段：体验升级】
  ├── 1. 常用应用收藏与最近访问记录
  ├── 2. 全局 Cmd+K 搜索框
  └── 3. 审计日志（记录应用点击量）

【第三阶段：深度集成】
  ├── 1. 动态 RBAC 权限（按部门/角色显示卡片）
  ├── 2. 首页 Widget 微卡片数据嵌合
  └── 3. 致远 OA 待办事项数量聚合
```

从目前的架构来看，第一阶段的“动态应用数据库 + 健康探活 + 单点登出”性价比最高，既能摆脱后续频繁改代码的麻烦，又能实时掌握所有 Node.js 服务的健康度。
